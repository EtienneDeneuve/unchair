## Privacy rules for these files

- No real faces or camera frames — posture preview is a synthetic skeleton stub
- Device IDs are placeholders (`uch_a1b2c3d4`), never a live machine id
- PNGs / GIF are re-encoded without EXIF / ICC identity baggage
- Desktop chrome / usernames from capture hosts are cropped out

Do not commit raw personal screenshots into this folder.
