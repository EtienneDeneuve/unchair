## Description

Unchair est une app de pauses macOS local-first.

La plupart des apps de pause demandent si vous avez bougé. Unchair peut vérifier — via Apple Vision optionnel, pendant une pause, entièrement sur l’appareil. Les images caméra restent en mémoire sur votre Mac. Elles ne sont jamais enregistrées ni envoyées.

**Ce que vous obtenez**

• Rappels dans la barre de menus, avec une boucle de pause claire  
• Vérification optionnelle assis→debout sur ce Mac  
• Vue Today avec l’historique local des pauses  
• Carte Human Runtime hebdomadaire respectueuse de la vie privée (exportable)  
• Fonctionne hors ligne pour le chemin principal planning → pause → historique  
• Mode dégradé si la caméra est refusée, occupée ou indisponible  

**Ce qu’Unchair n’est pas**

Unchair n’est pas un dispositif médical, un outil de diagnostic postural, un produit de surveillance employé, ni un remplacement de tracker fitness. L’app aide à prendre des pauses et, si vous l’activez, vérifie le mouvement localement.

**Intégrations optionnelles**

MQTT / Home Assistant et le scrape OpenMetrics local sont optionnels et désactivés par défaut. Les builds Mac App Store conservent le cœur local-first ; le réseau sandboxé suit les règles du canal MAS. Uniquement des événements de pause dérivés — jamais d’images, de landmarks ou de contenu de réunion.

**Confidentialité**

Pas de compte. Pas de télémétrie « phone-home » pour le produit de base. Contrat de confidentialité : https://github.com/EtienneDeneuve/unchair/blob/main/docs/PRIVACY.md

Nécessite macOS 14 ou plus récent.
