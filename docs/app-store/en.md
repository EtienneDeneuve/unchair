## Description

Unchair is a local-first macOS break app.

Most break apps ask whether you moved. Unchair can check — using optional on-device Apple Vision during a break. Camera frames stay in memory on your Mac. They are never saved or uploaded.

**What you get**

• Menu bar reminders with a clear break loop  
• Optional sit→stand movement verification on this Mac  
• Today view with local break history  
• Privacy-safe Human Runtime weekly card (exportable)  
• Works offline for the core schedule → break → history path  
• Fail-open when the camera is denied, busy, or unavailable  

**What Unchair is not**

Unchair is not a medical device, posture diagnostic, employee-monitoring tool, or fitness tracker replacement. It helps you take breaks and, if you opt in, verifies movement locally.

**Optional integrations**

MQTT / Home Assistant and local OpenMetrics scrape are optional and off by default. Mac App Store builds keep the local-first core; sandboxed networking follows the MAS channel rules. Derived break events only — never frames, landmarks, or meeting content.

**Privacy**

No account. No analytics phone-home for the core product. Read the privacy contract: https://github.com/EtienneDeneuve/unchair/blob/main/docs/PRIVACY.md

Requires macOS 14 or later.
